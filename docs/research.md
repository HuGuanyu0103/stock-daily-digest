# 标的详情页「当日解读」需求调研

> 本文档为需求梳理阶段的调研沉淀，作为分析依据，不等于用户已确认的事实。竞品结论均附公开可核实信源；受工具限制未能内嵌真机截图处标注「待补高信源图」，并给出可取图的原始信源。

## 一、用户与场景 Context

- **目标用户**：使用手机端财富管理 App 的**普通投资者**，大多**无专业投资背景**，看不懂机构研报/快讯语言。
- **核心场景**：在自选/持仓列表看到某标的**当日涨跌** → 点进**标的详情页** → 想弄清"今天这只标的到底发生了什么"。
- **现状痛点**：详情页现有内容为**行情走势 + 几十条面向机构读者的研报摘要与快讯**；专业化、碎片化、机构视角，用户**看完仍说不出当天发生了什么**（信息过载 + 门槛错配）。
- **业务目标**：让普通用户能在**几分钟内看懂**自己关注的标的当天发生了什么。
- **下沉友好性佐证**：蚂蚁财富「蚂小财」月活 7000 万中 **45% 来自三线及以下城市**，验证"通俗表达 + 一句话解读"对小白/下沉用户的强需求。[AI帮你管钱·中国证券报](http://jnzstatic.cs.com.cn/zzb/htmlInfo/9fae6d3e8c3cf84fc68845b8c1336482.html)

## 二、竞品功能拆解（带截图）

### 2.1 同花顺（重要参考竞品）

**策略：客观数据模块常驻 + AI 白话解读叠加（双层结构）**

- **详情页「读懂当天」模块**：异动解读/盘中异动提醒（推送型）、短线精灵（实时异动信号）、资金流向（主力/超大单净额）、龙虎榜（上榜原因+席位明细）、消息面聚合（新闻/公告/研报多 Tab）、涨停复盘/异动股揭秘（逐只归因）。[同花顺个股页示例](https://stockpage.10jqka.com.cn/youth/300364/) ｜ [异动观察·涨停复盘](http://yuanchuang.10jqka.com.cn/zhangting/)
- **AI 白话解读（问财 / i问财）**：AI 投顾，主打"降低门槛、一句话完成专业级分析"，面向新手散户。涨跌归因从公司/业务/行业/情绪 4 维给白话结论，**每条数据带角标可溯源**。[i问财官网](https://www.aigc.cn/iwencai) ｜ [AI能帮炒股么·专项评测](https://ai-toutiao.com/news/256.html)
- **圈选式 AI 解读**：详情页有"红色小画笔"，圈出 K 线图/信息块一键 AI 解读——极低门槛的小白交互。
- **交互动线**：`走势图/异动信号（客观数据）→ 右上角机器人/圈选画笔 → 问财白话解读（带来源）→ 追问/找同题材股`。从个股页进 AI 时自动带入该股上下文与推荐问题。
- **归因文案风格（模板化）**：「今日走势 + 异动原因揭秘（编号列点）+ 题材归因 + 风险免责」。例："宗申动力今日触及涨停板…异动原因揭秘：1、据 2026 年报，控股子公司…CA500 航空活塞发动机已获民航局适航批准…"[异动观察](http://yuanchuang.10jqka.com.cn/zhangting/)
- **⚠️ 教训**：模板化归因被散户吐槽"牵强对号入座"。[雪球:异动原因吐槽](https://xueqiu.com/6225597725/377946990) → 归因需强绑定真实事件/公告，避免硬凑题材。

## 三、共性设计要点（业界普遍怎么做）

1. **形态：详情页原生"AI 解读卡片"为主，对话为辅**——把解读做成详情页内一张卡片（富途/东财/老虎），而非让小白主动去问；对话式作为深挖入口叠加。
2. **节奏化定时产出抓"当日"**：开盘前+收盘后"早晚报"是标配。小白不盯盘，"收盘后一版今天发生了什么"最契合。
3. **金字塔式信息结构**：一句话结论（今天为什么涨/跌）→ 多维展开（消息面/资金面/技术面/事件）→ 关联标的与风险 → 可点击深挖原文。
4. **把三类专业信息"翻译"**：研报→核心观点/评级变化摘要；快讯公告→事件-影响路径-相关行业-关联标的-风险的传导链；资金流/龙虎榜→"资金偏好哪些板块、是否与价格背离"的可读解释。
5. **克制与可信是分水岭**：无重要信息就不硬凑解读（富途范式）；每条数据可点击溯源（降幻觉、建信任）；全程免责声明+非投资建议。
6. **基金侧多一层**："净值≠估值"预期差解读 + 用户行为归因（陪伴式投教）。
7. **个性化入口是放大器**：自选/持仓是最佳个性化触点——"你的自选今天涨跌与原因""持仓盈亏归因"，是券商相对资讯平台的独有优势。

## 三点五、用户行为调研洞察（业务方提供，需求核心依据）

> 来源：业务方对用户使用行为与场景的调研结论（截图）。这批洞察直接修正了"当日解读=给涨跌找理由"的默认假设，是本需求定义的核心依据。

1. **用户不信任无出处的归因**：读到「因某消息下跌」这类结论后，普遍会追问消息出处、转去搜索引擎自行核对。→ 解读必须**可溯源、可验证**，否则用户流失到站外。
2. **多数查看发生在"平静日"**：平台数据显示，用户查看次数中**多数发生在标的当日涨跌幅不足 1% 的交易日**。→ 查看动机不只是"归因暴涨暴跌"，更是**日常习惯性的"看看还好吗"确认行为**；只服务大波动会漏掉大多数真实访问。
3. **平静日藏着资金/量能异动**：这些平静交易日里，**一部分标的的成交量或资金进出出现明显变化**。→ 价格没动≠什么都没发生，把"价格看不出、资金在动"的隐藏信号翻译出来对小白最有价值。
4. **信息与行情时间错位**：资讯库公告**相当一部分发布在收盘后或休市期间**。→ 解读的时间窗必须覆盖"上一交易时段结束到现在"，不能只框当日盘中；也印证收盘后/晨间总结节奏的合理性。
5. **涨跌未必有消息可归因**：**当日涨跌较大的标的中，有一批当天并无可对应的公开消息**。→ 强行"逢涨跌必归因"会编造牵强因果（雪球被吐槽之坑）；诚实做法是说明"今日无对应公开消息，波动或与资金/板块/大盘有关"。

**由此确立的需求内核（已与业务方对齐）：**
- **三位一体解读**：价格 + 消息/公告 + **资金流向/成交量异动**，三类信号都翻译成人话（非仅消息面）。
- **诚实归因原则**：无对应公开消息时，坦白说明并给出可看的资金/量能/板块线索，不硬凑因果。
- **服务"平静日 + 波动日"双场景**：平静日给"今日无大事/资金有异动"的安心确认，波动日给可溯源归因。
- **完整信息时间窗**：覆盖盘后与休市期间发布的公告。

## 三点六、MVP 框定与产品取舍（业务方想法 + 综合判断，已对齐）

> 来源：业务方《产品需求分析与 MVP 定义讨论》文档 + 本次综合判断。

**MVP 锚定"低波动日（涨跌幅<1%）"为重心，理由（三条独立支撑，不依赖决策卡点假设）：**
1. 用户多数访问发生在低波动日，是真实高频场景；
2. 大波动日公开信息稀缺，解释质量天花板低、风险大；
3. 低波动日存在量价背离，是真实存在但未被满足的需求。

**综合判断确立的 3 条关键修正：**
- **不按波动率门控输出**：每天点进来都要有解读卡片（陪伴），低波动日是"设计打磨 + 衡量成败的重心"，而非"唯一出场场景"。三层价值定位：大波动+有消息=行业基线；大波动+无消息=信任考验（诚实归因）；**低波动日量价信号=差异化护城河**。
- **明确取舍**：低波动优先 = 主动用"情绪峰值"换"高频 + 差异化"，此取舍写入非目标/权衡，用大波动日诚实归因接住焦虑用户的信任。
- **坚定解释型、不做决策辅助**：MVP 定位纯"解释 + 可验证"，不碰"该不该买卖"（投资建议合规红线 + 未验证）。

**升级项**：「量价信号解读」从加分项升为 **MVP P0**——低波动日它是主角，否则 MVP 在低波动日退化为空卡片。

**待验证假设（作为 MVP 验证目标，不作前提）：**
- 低波动日用户是否处于"决策卡点"（vs 日常巡视/监控等待/异动感知）；
- 大波动日用户是否决策犹豫更低（经验直觉，缺数据）。
- 验证抓手：看完解读后跳出到站外核对比例↓（核心价值）、T+1/T+3 交易行为与停留时长（意图分层）、无消息卡片的有用率/跳出（诚实归因是否被接受）。

## 三点七、平台数据与能力家底（决定需求可行性与边界）

> 来源：业务方提供的平台数据/能力说明。这决定了需求"能不能做、做到什么程度"。

**已具备的数据源与能力：**
- **行情**（支撑价格维度）、**净值**（基金数据具备，二期基金解读有底）、**成分与持仓**（指数/基金归因）、**资讯库：公告/快讯/研报摘要，每条带发布时间与来源**、**公众平台文章 + 通用搜索结果**（社区/舆情信源）。
- **可读取用户的关注标的列表**（二期个性化/意图分层/Push 的数据基础）。
- **已接入通用大模型能力**（白话翻译的核心引擎已就位）。

**机会：**
- **O1 溯源与时间窗零成本落地**：资讯每条带"发布时间+来源"，直接支撑强制溯源与完整时间窗，不用额外建设。
- **O2 深度数据=护城河弹药**：成分/持仓/资金等"有的标的才有"的深度数据，正是竞品做不到的量价信号解读（P0）。
- **O3 多源交叉=可信度分级基础**：官方信源 vs 社区/搜索，可做信源分级。
- **O4 关注标的列表**：二期个性化与主动触达通路已通。
- **O5 基金数据齐全**：净值/成分/持仓，基金二期弹药就位。

**风险：**
- **R1/R4 数据项不一致**："各接口在不同标的上可返回的数据项并不一致"→ 冷门标的易残缺/空维度；且无法区分"真无异动"与"无数据"，可能误报"今日平稳"。
- **R2 大模型幻觉**：通用大模型可能编造消息/归因，直接冲突"可溯源、诚实归因"。
- **R3 社区/搜索信源不可控**：含噪音/谣言/荐股，引入不实信息与合规风险。
- **R5 净值/持仓时效**：基金净值 T+1、持仓定期披露，存在滞后，需标注口径。

**由此确立的两条产品规则（已与业务方对齐）：**
1. **数据可用性驱动优雅降级**（应对 R1/R4）：解读卡片按标的实际数据项动态组装，有则讲、无则不讲；明确区分"无异动"与"无数据"，缺失维度不展示也不误报。
2. **大模型约束 + 信源分级**（应对 R2/R3）：AI 只能基于平台给定数据源生成解读、禁止自行发挥编造；官方信源（公告/研报）为主归因，社区/搜索类降级标注为"网友讨论"、与官方信源隔离展示。

## 四、业务成功指标（含基线状态）

**核心行为指标**：解读卡片曝光→点击/展开率、解读内"查看详情/溯源"点击率、AI 追问/对话发起率。
**页面级参与**：详情页停留时长、解读模块阅读完成率、详情页跳出率下降。
**转化与留存（北极星方向）**：自选转化率、持仓/交易转化、次日/7日留存、早晚报打开率。
**质量与信任（防噪音归因）**：解读"有用率投票"、负反馈/举报率、准确性人工抽检、溯源可点击率。
**小白理解度（可选调研指标）**：看完后"能否用一句话说出今天发生了什么"自评正确率——直接对应核心痛点。

> 各指标现状基线：**待补充**（可从内部数据平台取详情页停留、跳出、自选转化等基线，本阶段不阻塞）。

## 五、业务约束与假设

- **合规红线**：金融内容须带免责声明、非投资建议；AI 生成需明示、须可溯源。
- **克制原则**：无实质信息的日子不硬凑归因，避免被识别为"事后找理由"的噪音。
- **数据分层假设**：客观数据（行情/资金/龙虎榜/公告）与 AI 主观解读需物理隔离，避免误导。
- **标的类型差异假设**：个股/指数/基金的"当日解读"逻辑不同，基金需处理"净值≠估值"。
